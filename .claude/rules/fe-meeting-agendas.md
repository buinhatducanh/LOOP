# FE Meeting Agendas — LOOP Solutions

> **Mục tiêu:** Mẫu agenda chuẩn cho các cuộc họp vận hành FE.
> **Cập nhật:** 2026-03-26

---

## 1) Weekly Planning (45 phút)

1. Review kết quả tuần trước (10')
2. Chốt mục tiêu tuần mới (10')
3. Capacity check + dependency check (10')
4. Risk review (10')
5. Decision log + action owners (5')

---

## 2) Mid-week Checkpoint (30 phút)

1. P0 status review
2. Blockers/escalations
3. Scope adjustments (nếu cần)
4. Release readiness sơ bộ

---

## 3) Sprint Review (45 phút)

1. Demo end-to-end flow
2. QA findings
3. KPI snapshot
4. Go/No-Go cho release (nếu có)

---

## 4) Retrospective (45 phút)

1. What went well
2. What didn’t
3. Root causes
4. Action items (owner + ETA)

---

## 5) Incident Sync (15-30 phút)

1. Current severity/impact
2. Mitigation progress
3. Next checkpoint time
4. Communication owner update
