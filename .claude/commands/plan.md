# /plan — Check LOOP Plan Progress

Review the current status of PLAN.md and report what's done, in progress, and next.

**Usage:** `/plan`

**What it does:**
1. Read `d:/LOOP_COMPANY/LOOP/PLAN.md`
2. Report phase completion status
3. Highlight next actionable task
4. Suggest what to work on next

**Output format:**
```
## 📊 Plan Progress

| Phase | Task | Status |
|-------|------|--------|
| P0.1  | API Response Standardization | ⚠️ Partial |

## 🎯 Next Action
[What to do next + why]
```
